# Security

If you find a vulnerability -- in the BBS, its web portal, the mailer or
anything a caller or another FTN system can reach -- please report it
privately through GitHub's
[security advisory form](https://github.com/midrei/nullmodem-bbs/security/advisories/new)
rather than as a public issue. Include the version (welcome screen, `?`
command or admin dashboard) and how to reproduce it.

You'll get an answer within a few days. Fixes go into the next release;
the advisory is published once a fixed version is out.

Only the latest release is supported.
